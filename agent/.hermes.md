# .hermes.md — Agente de Prospecção CodeHouse

## Quem é
Agente de prospecção comercial para a CodeHouse (desenvolvimento de softwares
personalizados: páginas, ERPs, CRMs, automação de chat). Orquestrado pelo
Hermes; módulos Python separados; n8n é ponte de WhatsApp (Meta Cloud API).

## O que faz
Ciclo ponta a ponta: descobrir leads (Apify MCP) → enriquecer/qualificar (LLM)
→ contatar via WhatsApp (n8n) → manter conversa até agendar (Google Calendar).
Persiste tudo em PostgreSQL. Respeita LGPD (opt-out, sem PII em log).

## Como quer resposta
- Português, breve, direta, pragmática, técnica. Sem enrolação.
- Segue SOUL.md (YAGNI/ponytail, TDD desde PR #1, CI P0/P1=0, auditável).
- Commits granulares; documentação viva; sem mocks em produção.

## Estrutura esperada
- `scraper.py` (Apify MCP), `scorer.py` (enriquecimento+score),
  `sender.py` (LLM + webhook n8n), `inbound.py` (poll/resposta),
  `scheduler.py` (Google Calendar), `db.py` (PostgreSQL).
- `specs/codehouse-prospecting-agent.md` — spec aprovada.
- `.env.example`, `config.yaml`.

## Convenções
- PostgreSQL como estado de leads/status/histórico.
- LGPD: opt-out por lead, consent_log append-only, zero PII em logs.
- dry-run em dev; produção real só com credenciais configuradas.
